# Cloud Security Tools 🛡️

## Description
Ushbu loyiha AWS bulutli infratuzilmasi xavfsizligini ta'minlash uchun yaratilgan Python vositalarini o'z ichiga oladi. Asosiy maqsad — S3 bucketlar xavfsizligini tekshirish.

## 🛠️ Loyihalar
- **S3 Bucket Scanner**: AWS S3 bucketlarining kirish huquqlarini (ACL) tekshiradi va "Public" (ochiq) bo'lganlarini aniqlab beradi.

## 🚀 Qanday ishlatiladi?
1. AWS hisobingiz uchun sozlamalarni (credentials) tayyorlang.
2. `boto3` kutubxonasini o'rnating: `pip install boto3`
3. Skriptni ishga tushiring: `python s3_scanner.py`

Cloud & Security talabasi tomonidan yaratilgan.
